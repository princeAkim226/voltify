# Journal des versions

Les puces de chaque section sont affichées **dans l'app**, au client qui décide
s'il accepte de télécharger 23 Mo. Les écrire pour lui : ce qu'il va remarquer,
pas ce qu'on a changé dans le code.

`scripts/make_version_json.mjs` lit la section correspondant à la version de
`pubspec.yaml`. Sans elle, la publication s'arrête.
